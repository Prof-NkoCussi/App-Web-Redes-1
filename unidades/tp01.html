1. ¿Qué son los datos?

Del dato a la información

  1. Dato

    Un valor aislado.

  2. Contexto

    Le da significado al dato.

  3. Información

    Un dato con significado útil.

  4. Conocimiento

    Permite tomar decisiones.

Un dato es un valor aislado, como un número, una palabra o una fecha. Cuando ese dato se interpreta dentro de un contexto, se convierte en información útil. Al analizar mucha información, podemos descubrir patrones y construir conocimiento.

Ejemplos en la vida real

Misma realidad,
distinto nivel de significado

  1. Dato

    38

    Dato: 38

  2. Información

    38 alumnos
    en 2° A

    Información:
    38 alumnos en 2° A

  3. Conocimiento

    el curso con más alumnos necesita más materiales

    Conocimiento:
    el curso con más alumnos necesita más materiales

Idea clave: los datos por sí solos no explican nada; necesitan contexto.

2. ¿Qué es una base de datos?

Organizar, guardar y consultar

Una base de datos es un conjunto organizado de datos relacionados, almacenados para poder consultarlos, modificarlos y analizarlos con facilidad.

  1. Datos

    nombres, fechas, precios

  2. Organización

    se agrupan con orden

  3. Almacenamiento

    quedan guardados

  4. Consulta

    se buscan y usan rápido

¿Qué puede guardar?

  • Personas
  • Productos
  • Ventas
  • Turnos

Ejemplo

Una escuela puede guardar alumnos, cursos, docentes y asistencias.

Idea clave: Una base de datos no es solo guardar información: es guardarla con orden.

3. Bases de datos en la vida cotidiana

Mucho más cerca de lo que parece

Las bases de datos están presentes en muchos sistemas que usamos todos los días.

  • Escuela

    alumnos, materias y asistencias

  • Comercio

    productos, precios y ventas

  • Hospital

    pacientes, turnos e historias clínicas

  • Banco

    cuentas, movimientos y clientes

  • Red social

    usuarios, publicaciones y mensajes

  • Streaming

    series, perfiles e historial

¿Qué tienen en común?

  • Guardan datos
  • Permiten buscarlos
  • Ayudan a tomar decisiones

Idea clave: Si un sistema guarda, relaciona y recupera información, probablemente usa una base de datos.

4. Base de datos vs. hoja de cálculo

Parecidas, pero no iguales

  • Hoja de cálculo

    Ideal para organizar y calcular datos simples.

  • Base de datos

    Pensada para almacenar, relacionar y administrar grandes cantidades de datos.

Comparación entre una hoja de cálculo y una base de datos
AspectoHoja de cálculoBase de datos
Uso ideallistas y cálculosmuchos datos relacionados
Volumenpequeño o mediogrande
Relacioneslimitadasentre varias tablas
Trabajo en equipobásicomás controlado
Seguridadsimplemás robusta
Consultasmanualescon SQL

¿Cuándo conviene cada una?

  • Para una lista simple de gastos, una hoja de cálculo puede alcanzar.
  • Para una tienda con clientes, productos y ventas, conviene una base de datos.

Idea clave: Una hoja de cálculo sirve para organizar datos; una base de datos está pensada para administrarlos mejor y relacionarlos.

+ Para profundizar

Un poco más sobre cada lámina

Lámina 1

Un dato, varios significados

Un dato suelto no dice nada: 25 puede ser una edad, un precio o el día de un mes. Cuando sabemos de qué se trata (el contexto) se transforma en información.

Al reunir y comparar mucha información aparece el conocimiento: algo que sirve para decidir.

Ejemplo en la escuela

  • Dato: 3
  • Información: Lucía faltó 3 veces en marzo.
  • Conocimiento: en todo el curso, los lunes falta más gente; conviene no tomar evaluaciones ese día.

Lámina 2

Cómo reconocer una base de datos

  • Datos relacionados: todos tratan sobre un mismo tema.
  • Organización: de cada elemento se guarda siempre lo mismo (de cada alumno: nombre, curso y edad).
  • Permanencia: no se pierden al apagar la computadora.
  • Consulta y actualización: se puede buscar, agregar, modificar y borrar.

¿Es o no es?

Sí: los contactos del celular. De cada persona se guarda nombre y teléfono, quedan guardados y se pueden buscar.

No: papeles sueltos en un cajón. No tienen orden ni una forma rápida de buscar.

Lámina 3

¿Cómo se hacía antes?

Antes de las computadoras, la información se guardaba en papel: fichas, carpetas y archiveros. Una escuela tenía un legajo por alumno; una biblioteca, una tarjeta por libro.

Las bases de datos digitales resolvieron esos problemas: se busca en segundos, hay copias de seguridad y varias personas trabajan a la vez.

Problemas del papel

  • Buscar llevaba mucho tiempo.
  • Había un solo ejemplar: si se perdía o se mojaba, no había copia.
  • Solo una persona podía usarlo a la vez.
  • Cruzar información (alumnos y notas) era muy trabajoso.

Lámina 4

Un curso vs. toda la escuela

Una profesora anota las notas de sus 30 alumnos en una hoja de cálculo: es una sola lista y la usa ella sola, así que alcanza.

En toda la escuela hay cientos de alumnos y muchos docentes cargando notas a la vez. Con una base de datos, cada dato se guarda una sola vez, cada usuario tiene sus permisos y todos trabajan sobre la misma información.

Con hojas de cálculo pasaría esto

  • Cada nombre se repite en muchas hojas; si se corrige en una, queda mal en las otras.
  • Circulan varias copias y nadie sabe cuál es la última.
  • Cualquiera puede borrar o cambiar una celda sin querer.
