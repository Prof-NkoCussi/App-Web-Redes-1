5. Tablas, filas, columnas y registros

La estructura básica de una base de datos

Una tabla organiza la información en columnas y filas. Cada fila es un registro, es decir, un conjunto completo de datos sobre un elemento.

ALUMNOS
idnombrecursoedad
1Ana1º A13
2Luis2º B14
3Sofía1º A13
4Mateo3º C15
Fila

Esta fila es un registro completo.

Tabla

Esta es una tabla de alumnos.

Columna

Esta columna indica los nombres.

  • Tabla

    reúne información sobre un mismo tema.

  • Columna

    indica qué dato se guarda.

  • Fila

    muestra una entrada completa.

  • Registro

    es cada fila con sus datos.

Lectura rápida

En la fila 2 aparece un alumno completo. La columna nombre guarda los nombres.

Idea clave: Una tabla ordena datos; las columnas definen qué guardar y las filas muestran cada registro.

6. Entidades y atributos

Qué se guarda y qué se describe

Una entidad es el objeto o concepto que queremos guardar en una base de datos, y los atributos son las piezas de información que la describen.

  • Entidad: Alumno

    Atributos (ejemplos)

    • nombre
    • edad
    • curso
    • email

  • Entidad: Producto

    Atributos (ejemplos)

    • nombre
    • precio
    • stock
    • categoría

  • Entidad: Turno

    Atributos (ejemplos)

    • fecha
    • hora
    • paciente
    • profesional

¿Cómo reconocerlos?

Entidad = sustantivo

Nombra un objeto o concepto que queremos guardar.

Ejemplos: Alumno, Producto, Cliente.

Atributo = característica

Es una pieza de información que describe a la entidad.

Ejemplos: nombre, precio, fecha.

Ejemplo

Si la entidad es CLIENTE, algunos atributos pueden ser nombre, teléfono y ciudad.

Idea clave: Primero definimos la entidad; después elegimos los atributos que la describen.

7. Tipos de datos

Qué clase de valor puede guardar cada campo

Cada campo de una base de datos guarda un cierto tipo de valor, y elegir el tipo correcto ayuda a organizar los datos y a validarlos.

  • Texto

    nombre, ciudad

  • Entero

    123

    edad, cantidad

  • Decimal

    3.14

    precio, promedio

  • Fecha

    12/05/2026

  • Hora

    14:30

  • Booleano

    sí / no

¿Por qué importa?

  • evita errores
  • ordena mejor
  • ayuda a consultar

Ejemplo

En una tabla de productos, precio debería ser decimal y stock debería ser entero.

Idea clave: No todos los datos son iguales: cada campo necesita un tipo adecuado.

+ Para profundizar

Un poco más sobre cada lámina

Lámina 5

Columna, campo y celda

A cada columna también se la llama campo: es el lugar donde se guarda el mismo dato para todos los registros.

Donde se cruzan una fila y una columna hay una celda, que guarda un solo valor. Las columnas se definen al armar la tabla; las filas se suman o se quitan a medida que se usa.

Leamos la tabla ALUMNOS

  • Tiene 4 campos: id, nombre, curso y edad.
  • Tiene 4 registros: Ana, Luis, Sofía y Mateo.
  • El valor 2º B está en el campo curso del registro de Luis.

Lámina 6

De la entidad a la tabla

Cuando armamos la base, cada entidad se convierte en una tabla y cada atributo, en una columna.

Ojo: “Alumno” es la entidad; Ana, Luis y Sofía son casos concretos de esa entidad, y cada uno ocupa un registro.

Así se corresponden

  • Entidad → tabla (ALUMNOS)
  • Atributo → columna o campo (nombre)
  • Cada caso → fila o registro (Ana, 1º A, 13)

Lámina 7

¿Número o texto?

Algunos datos parecen números, pero no lo son: el DNI, el teléfono o el código postal. Nunca vamos a sumarlos ni a calcular un promedio con ellos.

Una pista: si vamos a hacer cuentas con el dato, es un número; si solo lo vamos a leer o mostrar, conviene guardarlo como texto.

Qué puede salir mal

  • El teléfono 02901 42-1234 guardado como entero pierde el 0 del principio y el guion.
  • Un precio guardado como texto no se puede sumar ni ordenar de menor a mayor.

Todo junto

Armemos una tabla paso a paso

La biblioteca de la escuela quiere guardar sus libros. Primero elegimos la entidad (Libro), después los atributos y, por último, el tipo de dato de cada uno.

Recién ahí empezamos a cargar los registros, uno por libro.
